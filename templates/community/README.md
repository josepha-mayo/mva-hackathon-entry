# Identifier-free community toolkit

These files are public-safe handoff templates for another rare-disease team. They show the staged artifacts a lab can pass between cores without putting real alleles, medicines, or participant names into a public fork.

They are synthetic fixtures, not results from a person.

## Public fork versus private filled copies

1. Copy this directory into a public fork unchanged, or point collaborators at these filenames.
2. Duplicate a template into a private working folder **outside** the public checkout before any local biology names are filled in.
3. Keep filled biology-named copies private until a privacy review of the exact bytes that would be published.
4. If a public update is needed, export a new identifier-free summary that uses `SYN-` labels or lowercase hyphen ids only.

Do not open a public pull request, gist, issue, notebook, or chat paste with a filled copy that contains real gene, allele, medicine, sequence notation, chromosome positions, or participant identifiers. The public privacy gate will reject many of those shapes, but review is still required: passing an automated scan is not a license to publish a private case.

## What each handoff is for

| File | Core that fills it | What it records |
|---|---|---|
| `confirmation_record.synthetic.json` | clinical genetics | Orthogonal confirmation floors: identity, second aliquot, layout, both strands, producer, genomic library class, assay-matched specimen, and both synthetic alleles. An RNA library or unmatched-line DNA cannot confirm |
| `transcript_record.synthetic.json` | editing / RNA core | Stop-class and missense transcript fate. Unmeasured RNA cannot open a missense abundance assay. A computational predictor, protein-surrogate row, or unmatched-line RNA cannot stand in |
| `phase_record.synthetic.json` | clinical genetics | Direct phase for two synthetic alleles, molecule counts, guide configurations, haplotype linkage, strand balance, and assay-matched spanning-molecule specimen. A computational haplotype caller, RNA-seq phase, or unmatched-line spanning molecules cannot stand in |
| `coordinate_model.synthetic.pdb` | structural biology / reproducibility | Invented coordinates for the generic distance/contact engine; exact synthetic output is checked in separately |
| `structure_ranking.synthetic.json` | structural biology / program lead | Local geometry ranking of an exact residue versus analog-unstable and nearby-benign controls; not an assay |
| `allele_function_scorecard.synthetic.json` | proteomics / imaging | Abundance, half-life, localization, checkpoint, and first-division error by synthetic genotype. Wet basal cellular endogenous assay-matched rows only. Analog, homolog, or nearby cannot reverse an exact missense; an unmatched line cannot mint a hypomorph or reverse one |
| `measured_exposure_table.synthetic.json` | proteomics | Nominal bath concentration versus unbound medium and intracellular parent, with explicit duration, contact pattern, profile digest, and assay-execution support map |
| `blinded_count_table.synthetic.json` | imaging / statistics | Aggregate first-attempt counts with the public observed-run field names |
| `lineage_count_table.synthetic.json` | imaging / statistics | Timestamped-lineage first-attempt counts, competing-risk labels, and realized exposure/allocation context |
| `clone_safety_table.synthetic.json` | imaging / statistics | Three nested observed-label reproduction/death stops; selective daughter fitness or loss is not rescue |
| `assay_power.synthetic.json` | statistics | Locked imaging-power plan. Unlocking, shrinking, locking a pediatric completion crash, or treating a bulk-fraction drop as generation success cannot pass |
| `replication_decision.synthetic.json` | independent site | hold, advance, or stop after concordance, clone-safety, exposure, and a different originating site |
| `observed_inferred_unknown.synthetic.json` | all cores | Causal-chain links with non-interchangeable evidence status |
| `causal_chain_worksheet.synthetic.json` | program lead | Ordered gates from confirmation through oncology counterscreen, plus the declared next gate |
| `family_plain_language.synthetic.md` | clinical genetics | Clinician-facing blanks for what was found and what it does not mean |

Fill private copies in that order. A failed gate stops downstream spend: do not run a drug arm to fill the count table when phase is unresolved, and do not treat serum total as cell exposure.

The causal-chain links table is the input to the hypothesis-strength contract. Every link needs a `hypothesis_role`. Pair-program strength cannot exceed the weakest required link, including transcript fate. A call-set presence tick is not orthogonal confirmation. The checked-in table declares `experiment_to_run` and `declared_probe_is_medicine: false`. Declaring a conditional ex-vivo child claim while phase or RNA is unknown is a stop. A pair-program story with no kill-rule, competing explanation, or experimental controls is a stop. Labeling confirmation, phase, transcript, stability, probe, or endpoint observed while the nested gate is omitted or incomplete is a stop. Analog-allele, species-model, complementation, docking, geometry-ranking, coordinate-geometry, predicted-structure, in-silico, pathogenicity-score, ESM, REVEL, MAVE, frequency, conservation, ClinVar, official-label, software, software-catalog, database, ontology, literature, cell-free, ectopic, unmatched, imposed-stress, ranking, predictor, unlabeled, transgene, overexpression, computational, cDNA, transient, biophysical, thermal-shift, purified-protein, protein-surrogate, unmatched-line, RNA-seq, or computational-haplotype wording cannot count as exact-allele function. Heat-shock-family upregulation, lower bulk aneuploidy, selection, arrest, or death-masking cannot count as checkpoint rescue. Geometry ranking is assessed before confirmation; marking it `used_as_function` is a stop. A FoldX-on-AlphaFold or AlphaMissense ranking cannot pass. An exact-role residue that is not claimed as exact cannot open confirmation. Inflated pLDDT, RSA outside the unit interval, or negative polar contacts cannot pass either. A public software catalog, ranking engine, or predictor object cannot mint positive exact-allele, checkpoint, direct-target, or human-PD ledger evidence, cannot occupy lead or conditional-hold advancement, and cannot occupy a pharmacologic ranking role. A public database or ontology record cannot occupy those same pharmacologic roles or lead-advancement states. A derived_evidence row must name a non-derived parent source and inherits that parent's occupancy and mint bans; literature-derived parents remain eligible. An official medicine label cannot mint those same positive causal axes or occupy those same advancement states. Official-label comparator rows remain eligible. A parked comparator-only ledger row cannot carry a promote decision. Lead or conditional-hold advancement cannot carry a demote decision. A mechanistic-control or no-go row cannot occupy conditional hold. An active-lead row must occupy role lead; a challenger or comparator cannot hide as the active medicine.

The blinded count table uses the same field names as the public observed-run record (`arm`, integer `edit_event_id`, `clone_id`, `run_id`, `opportunities`, division counts, and daughter followed/reproduced/died counts). All thirteen shared counts are presence-required nonnegative integers in both tables, including the three first-attempt competing-risk counts; the optional daughter-slot and multipolar-division fields are identity-compared when present; a missing zero-valued daughter count is not silently treated as zero. Map local lab sheets onto those names; do not add latent or truth fields to a public table.

The lineage count table is a different contract. It keeps string event and clone ids and adds `pre_division_death`, `no_division`, and `dropout_censored`. The mapped blinded-table event, clone, and run keys must be positive integers; numeric strings, fractions, and Booleans are not coerced into identity. It also preserves the founder-derived study, functional execution, exposure-support record, exposure profile, probe/control, run, culture batch, exposure start, endpoint time, allocation id, and realized block/plate/well/dosing/acquisition tuple needed to join a realized result to its measured-exposure and pre-exposure allocation records. Allocation metadata are all-or-none. The exporter refuses to pool founders with different exposure or realized-allocation contexts into one aggregate row. Its source fingerprint canonically sorts rows and covers the study context, every shared count, exposure context, and realized allocation context; JSON row order cannot change source identity. Concordance is computed only from a locked, blinded table whose first-attempt outcomes partition opportunities, whose followed error daughters do not exceed two per error division, and whose clones are nested: a hero clone cannot pool a discordant clone into a pass, and one clone cannot represent an edit event. Increased no-division is competing cytostasis. Do not feed it to the v3 aggregate analyzer without an explicit mapping that you have tested. Do not drop pre-division death into a generic non-completion bucket.

The clone-safety v2 table is decided from those locked, blinded lineage counts and is nested under event, clone, and run. A pass requires at least eight followed daughters per arm in both observed label strata. It stops when the higher treatment-to-vehicle event-positive daughter reproduction rate exceeds `1.25`, when event-positive reproduction rises disproportionately to event-negative reproduction by more than `1.25`, or when the event-negative daughter death-rate ratio exceeds `2.0`; corresponding zero-control, positive-treatment cases are unbounded stops. Ratio thresholds must be finite and greater than one, and the follow-up floor must be a positive integer. These strict cutoffs and the eight-daughter floor are fail-closed software heuristics, not a power calculation or biological safety threshold. Observed event labels can be misclassified and do not establish true daughter genotype, rescue, safety, efficacy, or clinical benefit.

The measured-exposure table is the input to the exposure-gate contract. A nominal-only recipe cannot pass. A measured zero inside the cell cannot pass. Exploratory-only rows cannot advance. A row used to advance also needs a finite positive duration and declared contact pattern; a pulse additionally needs an explicit successful washout. Continuous contact does not require a row-level washout value. In this v1 table, `constant` means continuous contact, not analytically constant concentration; a lone single-point `pulse` row is supportive and cannot stand in for a measured post-washout concentration-time profile.

After the exposure object passes, the count-identity gate first requires every measured-exposure row to carry a canonical semantic profile id and unique measurement-execution id, then resolves every treatment execution exactly once to a selected measured execution. The profile id is recomputed from semantic fields, and the exposure object explicitly lists the functional executions and assay runs it supports, the culture batch, relation (`same_plate` or `matched_parallel_culture`), and actual timestamps. Each lineage row also names the support record it expected. No declared functional support or per-record assay run may be unused, and an unlinked row cannot declare functional assay context or evade audit by dropping its profile id. Functional execution ids are globally unique across every aggregate row and arm, including unpaired vehicle rows; measurement and vehicle-control record ids are disjoint. An unstratified treatment analysis uses one semantic profile, although distinct measurement executions of that same profile may support different batches. A valid row from a different run cannot rescue the counts. Each paired vehicle resolves to an explicit control record with a matched endpoint. Opaque public identifiers may point to private source records, but copied identifiers do not prove chain of custody, dosing, efficacy, or a physical sample match.

When functional executions are planned, the measured-exposure table carries a v3 allocation contract. Treatment is applied per functional-execution well; randomization and analysis use biological pairs; biological replication is at the clone/edit-event level. Each event x clone x run pair contains exactly one vehicle and one treatment execution in the same declared plate, batch, run, allocation block, **exact row**, and coarse position strata. Every plate x batch x run x event context requires at least six pairs and exact equality of the per-arm plate-column distributions. Before any seed commitment, the public enumerator keeps only context vectors retaining at least 75% of their centered arm-indicator information after the frozen context-specific dosing/acquisition linear, squared, and cross-product adjustment. The joint support must contain 64 to 1,000,000 vectors. A separate pre-reveal record holds the v4 input digest over the canonical manifest, exact canonical support ordering, support count and digest, assignment algorithm, rejection generator, and selection rule. A second record holds the experiment-bound v3 seed commitment. The exact order is lock, input record, seed record, reveal, selected-vector record, final-plan record, then exposure, with four distinct record ids. The accepted raw 256-bit draw indexes the canonical support directly; the incomplete modulo bucket is rejected without a synthesized redraw. Seed reveal, support, selected index, and selected vector must replay exactly; later lineage rows reproduce the committed realized tuple. Allocation and inference use digest-bound explicit left-to-right binary64 reductions. At count identity, both raw generation endpoints must be lower and both equal-pair-weighted one-sided randomization p-values must be at most 0.05. Exactness is conditional on rejection acceptance and only for the global Fisher sharp null of no effect on any execution under the declared uniform assignment model, not for a weak zero-average-effect null. The genuine uniform pre-outcome draw, consistency, no interference/carryover/cross-well contamination, fixed-manifest/no-exclusion, and arm-blinded ascertainment assumptions are `not_software_attested`. Lineage/exposure synthetic classification disagreement fails closed. Current unattested entropy permits a conditional synthetic pass; non-synthetic inference requires authenticated randomization and otherwise holds.

The private save-path helper replays one caller-declared fixed synthetic seed and relabels already synthetic arm-dependent payloads within complete pairs. Its executable guards require the synthetic exposure schema and privacy class, `synthetic_only` lineage, and unattested entropy. It does not search seeds. Never use it to reseal observed, controlled, or real data, and never choose a seed because it produces a favorable allocation or outcome. These checks do not prove entropy honesty, timestamp authenticity, physical placement, dosing, acquisition order, chain of custody, rescue, or efficacy. The complete contract is in `reports/TRACK2_RANDOMIZATION_CONTRACT.md`.

Phase, scorecard, and replication templates are inputs to the program gates. A declared trans call is overridden when molecule floors fail, haplotype linkage is missing or disagrees, recovered counts still look like dropout, or strand balance is outside the allowed band. A computational haplotype caller or RNA-seq phase cannot stand in for spanning molecules or parental genotypes. Spanning molecules from an unmatched genotype line cannot stand in. Parental genotypes may still pass when the specimen is parental. A missense stability defect on the **exact** allele is required before a chaperone-style probe is eligible. Analog, homolog, or nearby alleles cannot stand in, including analog recreation. Unlabeled recreation specificity cannot stand in. Exact correction must reverse the missense-positive endpoints in a wet cellular basal endogenous assay on the confirmed assay line. Analog, homolog, or nearby parked on `exact_corrected` cannot reverse an exact missense. An unmatched-line correction cannot reverse an assay-matched missense defect. Reciprocal recreation must restore those same endpoints in a wet cellular assay. A positive function call must be basal, not confined to imposed extrinsic stress. A positive function call must be cellular; a purified-protein thermal shift labeled wet cannot stand in for a defect or for genetic reversal. A positive function call must be endogenous; a transgene, cDNA, or overexpression row cannot mint a hypomorph. An unmatched genotype line cannot mint an assay-matched hypomorph. An ectopic WT construct cannot reverse an endogenous missense defect. An imposed-stress correction cannot reverse a basal missense defect. Green booleans on the replication record cannot advance without nested clone-safety, exposure, computed-concordance, hypomorph, and hypothesis passes. Concordance is counted from lineage tables, not ticked: both generation endpoints must fall, completion must stay inside the pediatric band, and at least three edit events are required. Replication still holds until checkpoint-ready is true and the nested child claim is conditional ex-vivo.

The causal-chain worksheet must declare `declared_next_gate_id`. Identity (confirmation, phase, transcript) ranks first. A probe, imaging, or replication spend while those are open is a stop. Declaring phase or transcript while confirmation is still open is also a stop. An unrecognized declared gate cannot stand in. After identity is complete, imaging or replication cannot skip the missense assay.

A 100 µM row beside a conservative-window row is an exposure stop. Family copy cannot claim checkpoint rescue. Nested k-mer ticks on a truncated lane set cannot confirm. An RNA or RNA-derived library cannot confirm genomic genotype even when k-mer floors are complete. Unlabeled library class cannot stand in. Genomic DNA from an unmatched genotype line cannot stand in for the confirmed assay line.

The assay-power plan must be locked before unblinding. A 36-opportunity table is not automatically powered unless the locked plan says so.

Coordinate geometry can only describe one supplied static model. Geometry ranking can only change the order of wet assays. Predicted stability cannot stand in for function. RSA must be a unit fraction, polar contacts must be a whole-number count, and pLDDT must be a percent; out-of-range features cannot open confirmation. The three role rows must carry distinct residue ids, including after case folding. Extra residues, missing control roles, or duplicate roles cannot hide a homolog or analog claim.

Run the ordered pipeline from the repository root:

```powershell
python scripts/run_community_gates.py --community templates/community
python scripts/run_save_path_simulation.py
python scripts/assess_method_delta.py
python scripts/run_coordinate_geometry.py --pdb templates/community/coordinate_model.synthetic.pdb --chain A --target 10 --comparators 20 30 --source-name coordinate_model.synthetic.pdb --ca-shell 6 --sidechain-contact 1.5 --polar-proximity 1.5
```

The checked-in synthetic toolkit holds at confirmation because the public confirmation record is incomplete. That is intended. The next-experiment chooser still runs and ranks confirmation first. A cis phase call, or an `observed` label on a trans-in-a-real-genome statement, stops later gates. Do not evaluate a drug arm after an earlier fail. The save-path simulation copies the same toolkit, fills constructed complete synthetic lab objects, and checks that a synthetic nested path can still advance. The current replay opens **1/1 constructed synthetic true path** and blocks **126/126 synthetic false paths from advancing: 100 final stops, 22 final holds, 4 contract-violation errors**. Current v2 save-path records say `blocked_from_advancing`; only historical v1 receipts used `killed` for any non-advance. These are configured software cases, not falsifications, independent experiments, or biological evidence.

## Family-facing language

`family_plain_language.synthetic.md` is a clinician-facing worksheet. It is not a letter to send to a family, not a diagnosis, and not a care-plan change. Research findings do not replace clinical advice from a qualified care team.

Do not request an invasive biopsy solely to complete these templates. Prefer residual clinical material already obtained for care, or an already obtained culture, when governance allows.

Do not put a real participant name, date of birth, medical-record number, or coded hospital identifier into a public fork. Leave the bracketed blanks empty in public copies.

## Review before any public commit

From the repository root:

```powershell
python scripts/privacy_gate.py .
```

Publish only identifier-free files that still use `SYN-` prefixes or lowercase hyphen ids. Filled biology-named copies stay private until that privacy review.
