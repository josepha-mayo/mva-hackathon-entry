# Track 2 method improvements (running list)

Status: public software log only. This file names no subject-specific gene, allele, or medicine. It does not authorize an upload and does not raise a survival percentage.

Desktop software cannot phase a genome, assay a missense allele, or give a medicine. Each row below is a method change that either opens the right next measurement or blocks a false-rescue story from advancing before a culture window is spent.
